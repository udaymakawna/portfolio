## 🌟 Key Features of this Build

I treated this website like a game level—optimizing performance, ensuring smooth navigation, and adding "juice" (feedback) to every interaction.

### 🎨 Visual & Experience Design
- **Glassmorphism Theme**: Custom-tuned blur and transparency effects for a premium, modern feel.
- **Dynamic 3D Elements**: Integrated Three.js to create the interactive particle background and running 3D shapes.
- **Glow Effects**: Custom CSS-based glow shadows that react to user interaction, replacing standard borders.

### 🕹️ Interactive Playground
I included a "Playground" section to demonstrate logic and interactivity:
- **3D Cube Runner**: A physics demo using Three.js.
- **Particle System**: A procedural generation test.
- **Memory Match**: A classic game loop implementation.
- **Reaction Test**: A simple state-management test.

## 🛠️ The Tech Stack

I chose a lightweight, performance-first stack for this site:

| Component | Technology | Why? |
|-----------|------------|------|
| **Core** | HTML5, CSS3 | Semantic structure and GPU-accelerated animations |
| **Logic** | Vanilla JavaScript (ES6+) | No frameworks overhead, pure control |
| **3D Engine** | Three.js | For handling WebGL content and particles |
| **Styling** | CSS Variables & Flex/Grid | Responsive design system without bloat |
| **Backend** | EmailJS | Serverless contact form handling |
